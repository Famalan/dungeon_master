## Условия задания

### 1. Реализовать 1-2 нетривиальные механики

Список механик на выбор:
1. Кроссплатформенный провайдинг — система генерации ресурсов
2. Пространственное кеширование руками — кеширование удалённых объектов для восстановления
3. Телепортация через портал — порталы для перемещения объектов/персонажей
4. Самонаводящиеся ракеты — оружие с самонаведением
5. Разрушение метеоритов
6. Система управления траекторией метеоритов
7. Боевые и вспомогательные дроны
8. Повреждение корабля — система повреждений с визуализацией и ремонтом
9. Corn механика — сельское хозяйство, выращивание и сбор ресурсов
10. Physics-Based Manipulation — захват, бросок
11. **Иная механика (требует одобрения преподавателя)**

### 2. Использовать встроенные инструменты / технологии

Список технологий на выбор:
1. Батчинг — объединение объектов для уменьшения draw calls
2. Запекание освещения — предрасчёт освещения
3. Встраивание собственного визуального эффекта в рендер-пайплайн (шейдеры/постобработка)
4. VR — иммерсивная среда
5. **Реализация собственного инструмента (требует одобрения преподавателя)**

> Пункты 1 и 2 можно частично заместить разработкой простых инструментов для самих себя.

### 3. Меню игры

- Кнопка «Начать игру»
- Кнопка «Опции»
- Кнопка «Выход»

### 4. Оптимизация

Чек-лист:
- [ ] Profiler или Stats в Unity
- [ ] Оптимизация 3D-моделей (полигоны, материалы, шейдеры)
- [ ] Оптимизация сложности (физика, код, эффекты)
- [ ] Статические объекты (`isStatic`)
- [ ] Static Batching
- [ ] Bake Lighting / Reflection Probe / Lighting Probe
- [ ] Настройки проекта под целевую платформу
- [ ] Frustum Culling
- [ ] Occlusion Culling

### 5. Отчётность

- Загрузить проект на GitHub
